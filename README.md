## 为什么国内用户总是卡在支付这一步

官方结账流程只支持境外 Visa / Mastercard，国内银行卡、支付宝、微信都不在官方支付方式里。很多人退而求其次去办虚拟卡，结果又倒在下面这几关：

1. 余额没算上税费，扣款时差一点被拒；
2. 所用的卡段本身不被 X 订阅支持；
3. 网络 IP 和账号常用地区冲突，触发风控；
4. 账单地址和发卡平台要求不一致。

每一条都要自己排查，开卡、养环境、填地址一整套流程走下来，还没开始用会员，先搭进去一个晚上。这就是代充存在的原因——把支付环节外包出去。
